# 全完成提示音设计

## 数据模型

- 在 `AppSettings` 增加 `allAgentsDoneSoundEnabled: boolean`，默认 `false`。
- 同步更新 Zod schema、默认状态、旧状态归一化以及 reducer 允许更新的设置字段。
- 增加 `allAgentsDoneSoundVolume: number`，默认 `0.7`，归一化时限制在 `0`～`1`。
- 全完成提示音使用独立音量字段，避免用户只开启全完成提示音时无法调节，也避免两种提示音互相牵连。

## 播放设计

- 原有单 Agent 完成音继续在单次正常完成回调中立即播放。
- 全完成音使用独立播放器与独立调度器，不通过 `else` 或共享 `Audio` 实例串行化，因此两个开关同时开启时可以并行触发。
- 每次正常完成都重新安排一次短暂稳定检查。检查时间晚于计时唤醒的完成稳定窗口，以便先释放可能被唤醒的下一批 Agent。
- 稳定检查时同时确认：
  - 没有活动 stream；
  - 没有状态仍为 `streaming` 的 Agent 卡；
  - 没有普通排队消息；
  - 没有计时唤醒待发送消息。
- 任何新 Agent 在检查前启动都会阻止本次全完成音。

## 音频资源

- 新增 `public/all-agents-done.wav`。
- 文件包含三个清晰、短促、递升的音，整体保持柔和，避免与原 `agent-done.wav` 混淆。
- 通过与现有 base URL 相同的 helper 解析资源路径，兼容 Web、Electron 和非根路径部署。

## UI

- 在设置“实用”分组中紧邻原完成音开关增加“全完成提示音”。
- 开关开启后显示独立音量滑杆和百分比；鼠标或触摸拖动结束时，用全完成三音资源试听当前音量。
- 沿用现有 `settings-toggle`，不新增边框、分组或装饰。
- 两套设置入口保持一致，中文和英文文案同步更新。

- 运行设置界面相关 Playwright/主题检查，确认亮暗主题没有布局回归。
