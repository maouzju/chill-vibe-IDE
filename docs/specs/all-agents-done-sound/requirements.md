# 全完成提示音需求

## 背景

当前设置只有“Agent 完成音效”，每个 Agent 正常完成时都会播放同一个单音提示。并行运行多个 Agent 时，用户还需要一个能明确表示“这一批工作已经全部结束”的不同提示。

## 需求

1. 设置 → 实用中新增独立的“全完成提示音”勾选项，默认关闭。
2. “全完成提示音”开启后显示独立音量滑杆，支持 0%～100% 调节，并在用户结束拖动时试听三音提示。
3. 全完成提示音开关和音量必须独立持久化；它们不受“Agent 完成音效”设置影响。
4. 每个 Agent 正常完成时，原有“Agent 完成音效”行为保持不变。
5. 某个 Agent 正常完成后，只有在当前不存在运行中 Agent、普通排队消息或计时唤醒待发送消息时，才播放“全完成提示音”。
6. 若两个开关都开启，最后一个 Agent 完成时两个提示都应播放；不能因为播放全完成提示而吞掉原有单 Agent 提示。
7. “全完成提示音”必须与原提示明显不同，并由连续的三个音组成。
8. 手动停止、等待重试和最终错误不算正常全完成，不播放全完成提示。
9. 新设置需要兼容旧状态：旧存档缺少开关时自动补为关闭，缺少音量时自动补为 70%。
10. 中文和英文设置界面都要有对应标签，并在亮色、暗色主题下保持现有设置项样式。

## 验收标准

- 只开“Agent 完成音效”：每个 Agent 完成播放原声音，全完成三音不播放。
- 只开“全完成提示音”：中间 Agent 完成不响，最后一个正常完成时播放三音。
- 只开“全完成提示音”时，也能直接看到并调整其独立音量，拖动结束会按当前音量试听。
- 两者都开：中间 Agent 只播放原声音，最后一个 Agent 同时触发原声音与三音。
- 两个音量设置互不影响，并分别控制对应提示音。
- 存在排队消息或计时唤醒待发送任务时，不提前播放三音。
- 重启应用后两个开关和两个音量各自保持原值。
