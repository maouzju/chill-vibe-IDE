# 自动更新可靠性需求

## 背景
应用更新检查依赖 GitHub Releases API。API 在共享出口触发限流时，设置页只显示检查失败，用户无法发现或安装已发布版本。

## 需求
1. GitHub API 检查失败或返回限流时，自动更新必须回退到公开 Releases 页面/Atom 数据源。
2. 回退仍需解析版本、平台资产和下载地址，不降低现有 ZIP 安装安全校验。
3. 版本解析支持稳定的三段 semver；无可用资产时显示明确错误。
4. 回退解析必须有单元测试，且不得访问用户提供的任意 URL。

## 安装阶段补充需求（2026-09-09）
5. “更新并重启”安装阶段必须单飞；重复点击不得启动第二个解包/替换作业。
