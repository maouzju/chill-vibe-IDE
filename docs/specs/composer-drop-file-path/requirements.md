# Composer 拖入文件 → 以路径形式插入

## 背景

用户把资源管理器里的文件拖到 agent 对话框（composer）上，目前什么都不会发生（甚至有可能被 Chromium 默认行为当成导航到 `file://`）。用户希望拖入时把文件的本地绝对路径以文本插入输入框，跟着这条消息一并发出去。与 `composer-paste-file-path` 是同一能力的第二个入口。

## 需求

1. 在 Electron 桌面端，把**非图片文件**拖到 composer 输入行（textarea 及其同行按钮区域）并松手时，把每个文件的绝对路径以文本插入到当前光标位置。
2. 路径格式、引号、空格补齐、光标落点与粘贴入口完全一致（复用 `formatPastedFilePathInsertion` / `insertTextAtSelection`）。
3. 图片文件（png/jpeg/webp/gif）拖入时进入图片附件（与粘贴一致），不插入路径。
4. 拖到 composer 上方悬停时给出可落下的视觉提示（drop-target 态），两套主题都要可辨。
5. 文件拖到窗口其他任何位置松手不得触发页面导航或替换整个界面；静默忽略。
6. 浏览器（非 Electron）模式拿不到本地路径：非图片文件被忽略，图片仍走附件；不产生导航。
7. 插入后草稿同步、slash 命令检测、高度自适应与手动输入一致。
8. 拖入不能影响已有的 pane tab / 看板项 / 列拖拽（那些用 `activeDragPayload`，不带 Files）。

## 非目标

- 把非图片文件作为附件上传。
- 拖入文件夹时递归展开（文件夹直接作为一个路径插入）。
