# Requirements — 飞书文档图片粘贴

## Goal
从飞书文档复制带图片的文字到 Chill Vibe 聊天输入框时，同时保留可编辑文字和图片附件，发送时图片随消息进入现有 provider 附件链路。

## Scope
- 继续支持系统剪贴板中的原生图片文件。
- 识别 HTML 剪贴板里的安全图片节点（`img[src]`），优先支持 data URL，并尽力下载可访问的 http(s) 图片。
- 保留 `text/plain` 文字内容并插入当前光标位置。
- 图片继续复用现有上传、草稿恢复、消息附件和 provider 路由。

## Non-goals
- 不绕过 CORS、登录态或外部站点权限。
- 不解析任意 HTML，不执行脚本，不修改原文档。
- 下载失败时不阻断文字粘贴。

## Verification
- 添加 HTML 图片源解析和混合文字/图片粘贴的聚焦测试。
- 运行相关 Node 测试、质量检查，并自动打包已验证修复。
