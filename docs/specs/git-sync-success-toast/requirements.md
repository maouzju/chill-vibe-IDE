# Git 同步完成飘字 — Requirements

## 背景

Git 工具卡点「同步」后会打开同步面板显示 pull → 冲突解决 → push 进度。
push 成功时面板停在 `done` 态，渲染一条成功横幅并带一个「关闭」按钮，
用户必须手动点一下才能把面板收掉、回到 Git 卡正常视图。

用户反馈：同步完成只需要一个自动消失的飘字提示，不需要一个必须点击关闭的窗口。

## 需求

1. **同步成功后面板自动收起。** push 成功即 `syncPanelOpen = false`、`syncStep = idle`，
   不再出现任何需要用户点击的成功态面板。
2. **成功以飘字形式呈现。** 成功文案走 Git 卡已有的 `notice` 通道（`tone: 'success'`），
   并在一小段时间后自动消失，无需用户交互。
3. **失败行为不变。** `error` 态仍然保留面板、保留「重试 / 取消」两个按钮 ——
   失败是需要用户决策的，不能飘走。
4. **后台同步同样生效。** hub 是模块级 store，卡片切到后台时同步照常进行；
   自动收起与飘字过期必须由 hub 负责，切回来时不应看到残留的成功面板。
5. **用户手动介入可提前结束飘字。** 任何会清 notice 的既有路径（如自动刷新）照常生效。

## 不在范围内

- 不改 pull / 冲突解决 / push 的进度展示。
- 不改 commit-new 等其它 notice 的现有行为（它们本就是横幅，复用同一通道但不强制过期）。
