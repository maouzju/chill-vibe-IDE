# 关闭后最小化到任务栏 — 需求

## 目标

为 Electron 桌面版新增一个可持久化选项。开启后，用户点击窗口关闭按钮时，Chill Vibe 不退出，也不中断正在运行的 Agent，而是最小化到系统任务栏。

## 功能需求

1. 设置 → 实用中新增“关闭后最小化到任务栏”开关，并提供简短说明。
2. 开关默认关闭；旧存档缺少该字段时也按关闭处理，保持当前“关闭即退出”的兼容行为。
3. 开启后，点击自定义标题栏关闭按钮或系统窗口关闭按钮：
   - 阻止窗口销毁；
   - 把窗口最小化到任务栏；
   - 保持 Electron 主进程、渲染进程和后台 Agent 任务继续运行。
4. 关闭开关后，窗口关闭继续走现有的状态刷盘后退出流程。
5. 应用明确退出、安装更新等已经进入退出流程的场景不得被该开关拦截。
6. 设置变更后应立即同步给 Electron 主进程，不要求重启应用。
7. 浏览器模式可以展示并保存该设置，但说明应明确它只影响桌面版。

## 验收标准

- 新安装和旧状态中，该开关均默认关闭。
- 开启开关后点击关闭，窗口进入最小化状态，应用进程和任务不退出。
- 从任务栏恢复窗口后，原页面和运行中任务仍在。
- 关闭开关后点击关闭，仍会完成现有持久化刷盘并退出。
- 中英文设置文案完整，设置页在明暗主题下沿用现有开关样式。
