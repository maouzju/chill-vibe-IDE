# 模型选择器：滚轮切换 + 自定义下拉项 — Requirements

2026-10-17 用户原话：「鼠标悬停在会话的模型选项卡上的时候，用滚轮可以控制模型的选择变为上一个或者下一个选项。然后在设置里需要有一个地方可以设置这个模型选项卡里面有哪些卡，可以关闭某些系统默认出现的卡，并且也可以额外加一些卡。」

## 范围

会话卡（ChatCard）上的模型选择按钮 `.model-select`，包括卡头与输入框两个位置（同一份 `renderModelSelect`），以及头脑风暴卡的「请求模型」选择器（同源列表）。

不在范围：自动化看板模板/待命 composer 的原生 `<select>`、超管 `create_session` 的可选模型目录（`listSelectableModelCatalog`）、斜杠命令 `/model`。

## 需求

1. **滚轮切换**：鼠标悬停在模型选择按钮上滚动滚轮，向上 = 下拉列表里的上一项，向下 = 下一项；到头/到底停住不循环。
   - 一齿一格；触控板的小 delta 累积到阈值才算一格（与思考档位旋钮同一判定）。
   - 滚轮在按钮上时不滚动外层页面/消息列表。
   - 卡片流式输出中（按钮禁用）滚轮无效；下拉菜单打开时滚轮不切换。
   - 连续滚过多个模型只算**一次**换模型：按钮文字立刻跟着变（预览），停手约 0.45 秒、鼠标移出按钮、或发送消息时才真正提交。换模型是复合动作（作废/保留 session、记 lastModel、上下文转移），逐格提交会让中间型号把会话状态折腾一遍。
   - 滚回原模型再停手 = 什么都没发生。
2. **设置里自定义下拉项**：设置 →「模型与对话」新增一组「模型下拉菜单」。
   - 列出所有内置模型选项（含「Codex/Claude/Gemini 默认」三项，不含工具卡），每项一个勾选框：勾上 = 出现在下拉里。
   - 默认勾选状态 = 当前内置可见性（已下架的型号默认不勾，用户可以勾回来）。
   - 只存用户改过的项（覆盖表），以后内置目录增删型号时，没碰过的项继续跟随内置默认。
   - 可以新增自定义项：选 provider（Codex / Claude / Gemini）+ 填模型名（+ 可选显示名），出现在下拉里；可以删除。
   - 模型名形状校验与 `/model` 自定义名一致（`customModelNamePattern`），工具卡令牌、本地模型令牌不收；与内置项或已有自定义项重复的不重复添加。
   - 一键「恢复默认」清空覆盖表（不删自定义项）。
3. **当前选中项永远可见**：卡上当前用的模型即便被用户关掉/已下架/是自定义名，也临时出现在下拉里（位置按目录原序），否则按钮显示与列表对不上、滚轮也找不到起点（pitfall #394 同款）。
4. **顺序**：本地模型条目 → 用户自定义项 → 内置项（目录顺序）。滚轮按这个顺序走。
5. 旧存档无新字段时按默认值升级，不改变任何人现有的下拉内容。

## 验收

- 单测：选项构建（覆盖表开/关、下架项勾回、自定义项去重、当前项补回、头脑风暴不含「默认」项）、滚轮步进（上/下/到头）、设置归一化（脏数据清洗）。
- Playwright：悬停滚轮后按钮文字变化、停手后卡片模型落盘为目标项、只触发一次换模型；设置里关掉一项后下拉里消失、加自定义项后下拉里出现。
- 视觉快照：设置「模型下拉菜单」分组 light/dark。
