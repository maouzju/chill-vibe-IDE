# 默认模型换代提示 — 需求

更新 Chill Vibe 后，若用户在「设置 → 模型」里配的默认模型已被内置的同档位新型号全面超越
（例：GPT-6 Sol → GPT-6.1 Sol），弹窗提示**一次**，弹窗内一键「设为新模型」。

- 只对「同档位换代」判定（Sol→Sol、Opus→Opus…）；Sonnet 默认不会被 Opus 顶替（那是价格取舍）。
- 自定义模型名 / 本地模型令牌 / 已是最新 → 不提示。
- 两个出口：「设为新模型」改全局默认并记已读；「保持不变」只记已读。点遮罩 / Esc 等同「保持不变」。
- 每条 provider+旧>新 只提示一次；已开会话与已存的卡模型不动（沿用 `updateRequestModels` 既有语义）。
- 全新安装不提示（不是「更新」）。老存档（settings 缺该字段）更新后提示。
