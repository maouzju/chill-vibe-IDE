# 便签图片附件 — 需求

## 背景

当前便签只能保存纯文本。用户在整理需求、截图和灵感时，需要把图片留在便签中，并能把同一张原图直接交给 Agent，而不是先另存文件、重新上传，或经过截图/转码后损失画质与动画帧。

## 需求

1. **插入图片**：便签工具栏提供图片插入入口，同时支持直接把剪贴板中的图片粘贴到便签。沿用 Agent 图片附件支持的 PNG、JPEG、WebP、GIF 格式与 10 MB 单图上限。
2. **原文件保存**：插入时复用本地图片附件存储，保存原始字节，不缩放、不重新编码；缩略图只影响显示尺寸。
3. **便签内展示**：图片按插入顺序显示在便签正文区域的安静缩略图带中。多图可横向浏览，不挤压正文到不可编辑。
4. **放大查看**：点击缩略图打开卡片外的放大预览；可通过关闭按钮、遮罩点击或 Escape 返回便签。
5. **无损复制到 Agent**：图片提供明确的“复制图片”操作，并支持缩略图聚焦后使用 Ctrl/Cmd+C。粘贴到任意 Agent 会话编辑框时，必须直接复用同一份本地附件及其原始字节，不能经由画布、截图或 PNG 重编码。
6. **普通粘贴兼容**：从便签复制的图片同时写入标准 HTML 剪贴板内容，便于粘贴到其他支持富文本图片的应用；Chill Vibe 自身优先识别内部附件元数据。
7. **持久化与历史**：当前便签的图片列表随本地便签保存、重新打开和重启恢复。历史版本同时记录当时的图片列表；恢复历史版本时，正文和图片一起恢复，并在恢复前保存当前正文与图片。
8. **移除图片**：每张缩略图提供低干扰的移除操作。移除只解除该便签的引用，不破坏已发送到 Agent 会话或其他便签仍在使用的附件。
9. **状态反馈**：上传、复制或保存失败时在便签内显示可读错误；上传期间不阻塞正文编辑。
10. **双主题与窄窗口**：缩略图、操作按钮、放大预览和上传状态在明暗主题及窄卡片中保持可见、可操作，闲置时不增加强边框或常驻装饰。

## 非目标

- 本阶段不实现图片在正文字符之间的自由排版、拖拽排序或图文环绕；图片以便签内附件带呈现。
- 不提供裁剪、标注、压缩或格式转换。
- 不做云端上传、跨设备同步或附件垃圾回收。
- 不保证外部应用如何再次编码图片；“无损”验收范围是便签到 Chill Vibe Agent 会话的复制粘贴链路。

## 验收标准

- 从文件选择器和系统剪贴板分别插入图片后，便签内出现清晰缩略图，正文仍可正常输入。
- 点击缩略图可以放大并正常关闭；明暗主题和窄卡片下均可用。
- 复制便签图片并粘贴到 Agent 编辑框后，只出现一份附件预览，附件 ID、文件名、MIME 与大小保持一致；发送时读取的文件字节与便签原图逐字节相同。
- 关闭并重新打开便签后图片仍存在；创建两个历史版本并恢复旧版本时，图片列表与旧版本一致，恢复前版本仍可撤销。
- 移除图片后当前便签不再显示该图，但已粘贴到 Agent 编辑框的附件仍可预览和发送。
