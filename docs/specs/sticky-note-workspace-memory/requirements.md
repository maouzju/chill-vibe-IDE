# 工作区便签库与历史版本 — 需求

## 背景

当前便签把“工作区记忆”压成每个工作区一份内容，并在恢复条里提供“删除记录”。这会导致多个便签互相覆盖，也让用户在应用内误删本地记录。便签需要升级为每个工作区可保存多份、彼此独立的本地文档。

## 需求

1. **不提供应用内删除**：便签界面移除“删除记录/删除便签”操作，改为“打开本地位置”。用户需要删除时，在系统文件管理器中自行处理对应的本地文件。
2. **一个工作区可有多个便签**：每张便签卡拥有稳定的 `stickyNoteId`，内容、标题、阅读位置和历史版本均按 `workspacePath + stickyNoteId` 隔离，不能再共享一份工作区级内容。
3. **可重命名**：沿用卡片标题编辑入口。标题修改后，本地便签文件名同步更新；重名通过稳定 ID 后缀避免冲突。便签标签页优先以正文第一行作为标题；第一行为空时回退到卡片标题，仍为空时显示“便签”。
4. **本地持久化**：便签以人可读的 Markdown 文件保存到 Chill Vibe 本地数据目录下的工作区专属文件夹。关闭卡片或工作区不删除文件。
5. **可重新打开**：新建的空便签卡应列出该工作区已有便签，用户可把其中一份绑定到当前卡片继续编辑。
6. **历史版本管理**：
   - 编辑停止一段时间、卡片卸载或主动恢复版本时创建自动检查点；
   - 历史面板按时间倒序展示版本时间与内容预览；
   - 用户可恢复任意历史版本；恢复前必须先保存当前内容为一个版本，保证恢复可撤销；
   - 每份便签最多保留 50 个版本，单个版本内容最多 64KB。
7. **兼容旧数据**：旧卡片只有 `stickyNote` 内容、没有 `stickyNoteId` 时，以卡片 ID 作为便签 ID，并在首次保存时迁移到本地便签文件。旧的工作区单份存档仍可作为一次性恢复来源，但不再继续覆盖多便签数据。
8. **独立阅读位置**：滚动位置与光标/选区保存到卡片自身，多个便签之间互不影响。
9. **双主题与窄窗口可用**：工具栏、已有便签列表、历史面板在明暗主题和窄视口下保持安静、可读、可操作。
10. **工作区便签搜索**：便签卡提供搜索入口，可按标题或当前正文内容检索本工作区的所有本地便签；搜索不区分英文大小写，支持中文，结果可直接打开，且不会混入其他工作区的便签。

## 非目标

- 不做云同步或跨设备同步。
- 不在应用内提供永久删除、批量清理或回收站。
- 不实现多人实时协作编辑。

## 验收标准

- 同一工作区同时打开两张便签，分别输入、重命名、查看历史，互不串内容或版本。
- 界面中不存在便签删除按钮，存在“打开本地位置”入口并能打开对应工作区便签目录。
- 关闭并重新打开工作区后，可从空便签卡看到并打开之前保存的多份便签。
- 恢复历史版本后，恢复前的内容仍出现在历史列表中。
- 输入标题或正文中的关键词后，只显示当前工作区内匹配的便签，并可直接打开。
